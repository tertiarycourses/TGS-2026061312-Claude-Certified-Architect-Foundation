description: Install (first time) and start the six simulators website, then open it in the browser.

Read `START-LABS.md` in the labs folder and follow it. Skip whatever is already done. On Windows, launch `start-labs.cmd` in its own window; on Mac, launch `start-labs.command`. Tell the learner to keep that window open, and give them the address it prints. Every lab calls Claude Haiku 5.5 with their Anthropic API key, saved once in labs/.env (the start script, set_api_key.py or the sidebar box asks for it).
