30 labs, one per task statement, then 10 code labs that show how it works

Day 1 runs the six official exam scenarios on simulators: for every one of the 30 task statements, answer an exam-style question, then watch the answer work live. Day 2 opens the code: API calls with curl and the Python SDK, a hand-written agent loop, subagents, an MCP server, Claude Code in CI, batches, caching and error handling.

Set up once. Clone the repo, open a terminal in labs/ and run uv run set_api_key.py to save your Anthropic API key to labs/.env (or paste it into the simulator website's sidebar). Every lab calls claude-haiku-5-5; a whole lab usually costs under one US cent.
